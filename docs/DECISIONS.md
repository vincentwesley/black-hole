# Decisions

Each entry: the call, then why. Newest last.

1. **Raw WebGL2, no three.js.** The whole scene is one full-screen fragment shader plus a few post passes. three.js would add ~600 KB to draw a single triangle and hide the render-target formats we need (RGBA16F). Raw WebGL2 keeps the JS bundle at ~27 KB and runs on SwiftShader in headless Chromium.
2. **Per-pixel geodesic integration, not precomputed tables.** The brief asks for lensing traced per pixel. Tables (Bruneton 2020) are faster but hide the physics; they stay the upgrade path for very weak GPUs (see PLAN.md).
3. **Cartesian form x'' = −(3/2) h² x / r⁵ with leapfrog steps ∝ r.** Same orbits as the Binet equation, no polar bookkeeping, symplectic (stable near the photon sphere), and one cheap acceleration per step. Unit tests check capture at b_crit ± 0.5 %, the weak-field 2 r_s/b deflection, and the exact strong-field deflection at b = 3 r_s.
4. **Static-observer camera with the correct local-to-coordinate mapping.** The radial component of each pixel's direction is scaled by √(1 − r_s/r) and b = r sin α / √(1 − r_s/r), so close-up views (down to 2.2 r_s) are right, not just the far-field approximation most demos use.
5. **Colour from physics.** Disk temperature from the Page–Thorne flux; observed colour from a Planck → CIE 1931 → linear sRGB table stored as unit-luminance RGB + ln Y. Doppler and gravitational shifts enter only as T → gT, which is exact for a blackbody (I_ν/ν³ invariance) and gives beaming and colour shift together.
6. **Two looks: Physical (default) and Film.** Film turns off every frequency shift, as the Interstellar team did (James et al. 2015 §4.2), and warms the disk. It makes the effect of Doppler beaming visible with one click.
7. **Disk texture is procedural, advected at the Keplerian rate.** No real data exists for gas turbulence; the brightness profile is physical, the streaks are an artistic modulation (two crossfaded phases so differential rotation never winds it into aliasing). Recorded here so nobody mistakes it for data.
8. **Real sky: Yale Bright Star Catalogue (9,096 stars) in galactic coordinates,** baked into a float cubemap at load, coloured from B−V. Galactic centre placed behind the hole, plane tilted 25°. 145 KB, public scientific catalogue. The NASA Deep Star Maps would add the Milky Way glow but only ship as 20 MB+ EXR; deferred.
9. **Quality presets Low / Medium / High / Ultra plus a governor.** Presets vary render scale, DPR cap, step budget, step size, bloom levels and sky resolution. First visit picks from hints (software renderer → Low, coarse pointer → Medium); the governor only steps down (no oscillation) after a 45-frame window over 34 ms. Choice persists in localStorage.
10. **Bloom: Jimenez 2014 13-tap down / tent up chain on RGBA16F, ACES fit tone curve.** Physically plausible glare without thresholds. Fallback when float targets are missing: the scene shader tone-maps directly to the canvas.
11. **GitHub Pages, not Cloudflare.** The brief says GitHub Pages. Pages cannot set headers, so the strict CSP moves to a `<meta http-equiv>` tag (`script-src 'self'`, no third-party hosts). `style-src 'unsafe-inline'` stays only because the house credits card positions its fireflies with inline CSS variables. Vite `base: "./"` so the build works at `/black-hole/` or any path.
12. **Page structure:** the render fills the first screen and stays dark in both themes (it is a picture of space); the house theme toggle switches only the page chrome. Explanations, references and controls help sit below, ending with the house credits card.
13. **Accessibility:** canvas is focusable with a descriptive label and full keyboard control; all controls are native inputs; reduced motion stops disk animation and turns cruise off by default; a still-frame fallback replaces the canvas without WebGL2.
14. **One "Deploy" workflow on push to main** (build + upload-pages-artifact + deploy-pages, SHAs pinned). CI stays the house reusable workflow, renamed nothing. Deploy does not re-run tests (CI already gates main via automerge) to save Actions minutes.
15. **Review fixes before the first push (code-review pass):** star data un-ignored (`!public/data/` — the house `data/` ignore would have shipped a starless site); cubemap mipmaps only when half-float is colour-renderable; GPU targets freed on preset change; star colours computed once; keys by `e.code`; wheel `deltaMode` handled; reset clears inertia; theme toggle reads the applied theme (works with storage blocked); Pages `configure-pages` runs first so a disabled Pages fails in seconds, and in-flight deploys are never cancelled.
16. **Milky Way glow from NASA SVS Deep Star Maps 2020** (`milkyway_2020_4k_gal.exr`, galactic, bright stars removed so it adds to the BSC stars without double counting). Decoded with `scripts/build-milkyway.py` (ZIP-compressed half-float EXR → 2048×1024 sRGB JPEG, 490 KB), uploaded as `SRGB8_ALPHA8` so the GPU linearises it, sampled per escaped ray with explicit gradients (seam-safe at l = ±180°). Brightness is tied to the stars: texture value 1 (its 99.95th percentile) = 20.5 V mag/arcsec², converted to star units (`MILKY_WAY_SCALE`). One **Sky brightness** slider scales stars and Milky Way together; default 2.5× because at true brightness the band all but disappears next to the disk.
17. **Cubemap solid-angle correction.** A filtered lookup averages over texels, and cube texels near face corners cover up to 5.2× less sky, so baked stars were dimmer there. Each star's flux is now divided by (1 + u² + v²)^(-3/2).
18. **Automerge dispatches Deploy after it merges.** Merges by automerge use `GITHUB_TOKEN`, and pushes made with that token start no `push` workflows, so the MVP merge never deployed. `workflow_dispatch` is the documented exception, so `automerge.yml` gained one `gh workflow run deploy.yml` step (+ `actions: write`). Not a `workflow_run` trigger on Automerge: that would also fire after every skipped Automerge run and spend Actions minutes on no-op deploys. `push: main` stays for merges made by a person.
19. **CI is self-contained.** It used to call `ci-node.yml` from the private `vincentwesley/house` repo; once this repo went public, GitHub refused to start it (a public repo cannot use a private repo's reusable workflow), so every PR failed with no jobs. `ci.yml` now carries the same steps inline: identity check (vincentwesley and Dependabot authors only), `npm ci --ignore-scripts`, typecheck, lint, unit tests, build, Playwright + axe. The workflow stays named `CI` for `automerge.yml`.
20. **The render no longer traps page scrolling (cooperative gestures).** The canvas filled the first screen and swallowed wheel and touch, so the page below (How it works, References, credits) was only reachable by scrolling over the control panel. Now: plain wheel scrolls the page and a short toast says "Hold Ctrl/⌘ and scroll to zoom"; Ctrl/⌘ + wheel and trackpad pinch zoom; on touch (`touch-action: pan-y`) a vertical swipe scrolls, a sideways drag orbits, two fingers tilt and pinch-zoom. Added on-screen +/− zoom buttons, section jump links under the title (How it works · Sources · Credits), a "More below" cue, and the stage stops 2.5rem short of the fold so the next card peeks in. Smooth anchor scrolling only without `prefers-reduced-motion`.
21. **UI pass 2: the panel shares the screen instead of covering the subject.** Audit at 1440/1024/768/390 px showed the panel hiding a third of the hole on laptops, half its controls behind an inner scroll, and covering the whole render on phones. Now: the panel is grouped (Look + one-line explanation, Effects as a 2-column toggle grid, Disk sliders, Image sliders in a collapsed group, Quality, actions, Reset all settings) and fits a 900 px-tall window without scrolling; it opens by default only at ≥ 1100×700 and then remembers the viewer's choice; when it sits beside the render, a principal-point shift (`uShift` in scene.frag, eased) centres the hole in the free area and the hint/cue/toast centre there too (`--free-right`); on phones it is a bottom sheet with a sticky header and the bottom HUD steps aside. Added Full screen (F, hidden where the Fullscreen API is missing, e.g. iPhone) and Hide interface (H, Esc or the "Show interface" button to return, focus moved accordingly).
